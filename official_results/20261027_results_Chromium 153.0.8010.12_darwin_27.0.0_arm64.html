Results for Lightning JS Framework benchmark

The benchmark was run on darwin 27.0.0 arm64 on a Apple M3 Max 14 and 36.00 GB memory

Tests where executed on browser version: Chromium 153.0.8010.12 using PlayWright

Results

Tests are run by executing an operation and waiting for the WebGL rennder to be Idle

Results are the time in milliseconds to execute the operation

All operations are executed on 6x CPU slowdown

Startup is measured from navigation start to the first idle after rendering 1,000 nodes (fresh browser context per run, 6x CPU slowdown applied before navigation, so JS fetch/parse is included)
